## Skills and plugins (overrides superpowers)

Match effort to task size. The superpowers plugin's "if there is even a 1% chance a skill applies, you MUST invoke it" rule does NOT apply. This instruction overrides it.

Skip skill workflows (brainstorming, systematic-debugging, test-driven-development, writing-plans, etc.) for small tasks:
- Answering a question, explaining code, reading a file
- A single-file edit with an obvious fix
- Mechanical changes: renames, config tweaks, typos, formatting
- Anything finishable correctly in one or two tool calls

Use skill workflows for real work:
- New features, new components, multi-file changes
- Bugs where the cause is unknown after a first look
- Anything needing a plan, or when I explicitly ask for a skill

When unsure, do the task and note that a skill was available. Do not announce skipped skills.
